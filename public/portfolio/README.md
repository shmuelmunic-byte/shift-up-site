# Portfolio assets — סקשן 7 בדף הבית

תיקייה זו מכילה את קבצי הקריאייטיב שמוצגים בגריד הפורטפוליו בדף הבית.

## איך להוסיף מודעה
1. גרור את קובץ התמונה לכאן (`public/portfolio/`).
2. שמור לפי המוסכמה: `{תחום}-{לקוח}.jpg` באנגלית, אותיות קטנות, מקפים.
   דוגמאות: `events-yehuda.jpg` · `realestate-villas.jpg` · `legal-skler.jpg` · `beauty-hili.jpg`
3. עדכן את הרשימה ב-`docs/portfolio-manifest.md` (filename + אישור הצגה).

## פורמט מומלץ
- JPG/WebP, רוחב ~1080px (מספיק לגריד), עד ~300KB לקובץ (לדחוס לפני העלאה).
- יחס: כפי שהן (מרובע/סטורי). הגריד יתאים את עצמו.

## קייס סטאדי (נפרד מהגריד)
פרויקט **City Transformer** מוצג כקייס מעמיק, לא בגריד. נכין לו תמונות/עמוד נפרד בזמן הבנייה.

> הגריד עצמו ייבנה במפגש הבנייה — כאן רק אוספים את הקבצים מראש.
