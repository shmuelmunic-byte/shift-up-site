## 1. נגישות — ת"י 5568 רמה AA + חוק שוויון זכויות לאנשים עם מוגבלות

### מה החוק דורש
- הנגשה לפי ת"י 5568 (מעוגן ב-WCAG 2.0 AA) ותקנות שוויון זכויות (התאמות נגישות לשירות), 2013.
- **הצהרת נגישות** בעמוד ייעודי — הדבר הראשון שתובעים בודקים.
- **רכז נגישות** עם איש קשר אנושי: שם + טלפון/מייל (לא רק טופס).
- **תפריט נגישות** (הגדלת טקסט, ניגודיות, עצירת אנימציות) — אך הווידג'ט לבדו **אינו מספיק**; האתר חייב להיות נגיש גם בקוד.
- טקסט חלופי (alt) לכל התמונות, ניגודיות ≥ 4.5:1, ניווט מקלדת מלא.
- **חשיפה:** עד 50,000 ₪ לכל הפרה ללא הוכחת נזק; תביעות ייצוגיות. קיימת **תקופת ריפוי של 60 יום** — יש לתת הודעה ואפשרות לתקן לפני שקמה עילה.

### מה יושם (קובץ אחר קובץ)
| קובץ | מה נעשה |
|------|---------|
| `src/pages/AccessibilityPage.jsx` | **חדש** — עמוד הצהרת נגישות מלא (מחויבות, אמצעים, מגבלות, פרטי רכז נגישות, תאריך). |
| `src/components/A11yWidget.jsx` | **חדש** — תפריט נגישות: הגדלת טקסט (100/115/130/150%), ניגודיות גבוהה, הדגשת קישורים, גופן קריא, עצירת אנימציות, סמן גדול, איפוס. נגיש למקלדת, `aria-pressed`/`aria-expanded`, קיצור `Alt+A`, שמירה ב-localStorage. |
| `src/components/LegalLayout.jsx` | **חדש** — פריסה משותפת לעמודים המשפטיים + **קישור "דלג לתוכן הראשי"**. |
| `index.html` | סקריפט bootstrap שמחיל את העדפות הנגישות **לפני** ריצת React (מונע הבהוב/FOUC). |
| `src/index.css` | מחלקות `.a11y-*` על `<html>`, סגנון `.skip-link`, `.a11y-sr-only`, סגנון הווידג'ט, ביטול פילטרים בהדפסה. |
| `src/main.jsx` | הווידג'ט מוצג גלובלית בכל הדפים; נוספו הנתיבים `/accessibility` ו-`/privacy`. |

- ✅ קישור "דלג לתוכן הראשי" נוסף לעמודים המשפטיים.

## 2. פרטיות — חוק הגנת הפרטיות תיקון 13 (בתוקף אוגוסט 2025)

### מה החוק דורש
- **עמוד מדיניות פרטיות** — איזה מידע נאסף, למה, ומה נעשה בו.
- **תיבת סימון בכל טופס** לאישור קריאת מדיניות הפרטיות **לפני** שליחה.
- **הודעת עוגיות/מעקב** (האתר מריץ Meta Pixel + GA4 → חובה).
- פירוט המידע הנאסף (שם, מייל, טלפון וכו') והצהרת אבטחת מידע.
- **הרחבת "מידע אישי"** בתיקון 13 לכלול IP, מיקום ומזהים מקוונים → אנליטיקה סטנדרטית נכנסת לתחולה.
- **חשיפה:** קנסות מנהליים כבדים (עד ~3.2M ₪ להפרות חמורות). האכיפה חיה (למשל קנס ל-HOT).

### מה יושם (קובץ אחר קובץ)
| קובץ | מה נעשה |
|------|---------|
| `src/pages/PrivacyPage.jsx` | **חדש** — מדיניות פרטיות מלאה: מי אנחנו, איזה מידע נאסף (טפסים + אוטומטי), עוגיות (GA4 + Meta Pixel), מטרות שימוש, דיוור, מסירה לצד ג', **אבטחת מידע**, זכויות הנושא, שינויים. |
| `src/components/CookieBanner.jsx` | **חדש** — הודעת עוגיות עם "אישור"/"דחייה" + קישור למדיניות. "דחייה" מפעילה `ga-disable` ל-GA4 ומסמנת סירוב ב-localStorage. |
| `index.html` | bootstrap שמכבד סירוב קודם ל-GA **לפני** אתחול GA. |
| `src/components/LeadForm.jsx` | **תיבת הסכמה למדיניות פרטיות** (לא מסומנת כברירת מחדל) — השליחה חסומה עד סימון; קישור למדיניות; הודעת שגיאה. לוגיקת ה-Supabase וה-WhatsApp fallback נשמרו במלואן. |
| `src/pages/DiagnosticPage.jsx` | אותה תיבת הסכמה חסומת-שליחה בטופס האבחון; שמירת ה-Supabase (best-effort) נשמרה. |
| `src/components/Footer.jsx` | קישור "מדיניות פרטיות" בכל עמוד. |

## 3. דיוור (חוק הספאם) — הערה בלבד

חוק התקשורת (בזק ושידורים) — סעיף 30א חל על **הדיוור בפועל** של Shift Up (מייל/וואטסאפ),
לא על טפסי האתר. הכללים: הסכמה מפורשת ונפרדת (opt-in), בלי תיבות מסומנות מראש, אפשרות
הסרה, זיהוי השולח, וסימון "פרסומת". **מומלץ** להוסיף בעתיד תיבת הסכמה שיווקית **נפרדת**
(unchecked) בטפסים היכן שרלוונטי. עמוד מדיניות הפרטיות כבר מציין שדיוור שיווקי יישלח רק
בהסכמה מפורשת ונפרדת עם אפשרות הסרה.

## מה עדיין דורש קלט/פעולה של בעל האתר (TODO ידני)

1. **פרטי רכז נגישות** — למלא ב-`src/pages/AccessibilityPage.jsx` את השדות:
   `[[מלא: שם רכז נגישות]]`, `[[מלא: טלפון]]`, `[[מלא: אימייל]]`. **חובה חוקית** — שם + איש קשר אנושי.
2. **בדיקת נגישות מקצועית** — הרצת בדיקה אמיתית עם קורא מסך (NVDA) + מבדק ידני מלא, ורצוי חוות דעת מורשה נגישות.
3. **בדיקה משפטית** — אישור נוסח מדיניות הפרטיות והצהרת הנגישות ע"י עו"ד.
4. **חסימת סקריפטים לפני הסכמה (שיפור עתידי):** כרגע GA4 ו-Meta Pixel נטענים ישירות מ-`<head>`.
   "דחייה" מכבה שליחת אירועים ב-GA4, אך **Meta Pixel כבר יורה PageView בטעינה**. לחסימה מלאה
   יש להעביר את אתחול הפיקסל/GA לטעינה מותנית-הסכמה (gate על תג ה-`<script>` עצמו).
5. **עצירת אנימציות — מגבלה:** מתג "עצירת אנימציות" עוצר אנימציות/מעברים של CSS. אנימציות
   **GSAP** (מבוססות-JS) אינן נעצרות דרכו; לכיסוי מלא יש לחבר את המתג ל-GSAP או להסתמך על `prefers-reduced-motion`.
6. **סמן מותאם:** האתר מסתיר את סמן העכבר (`cursor:none`) לטובת סמן מותאם. מתג "סמן גדול"
   בווידג'ט מחזיר סמן מערכת גדול וברור — ודא שזה מספק, או שקול חשיפת סמן ברירת-מחדל.
7. **רישום מאגר / DPO:** לפי תיקון 13, רישום נדרש בעיקר לגופים ציבוריים וסחר-נתונים. סביר
   שלא חל על Shift Up, אך יש לוודא מול עו"ד לפי היקף הנתונים בפועל.
